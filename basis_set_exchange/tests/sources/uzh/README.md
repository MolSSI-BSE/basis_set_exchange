# UZH protocol native GTH source

Associated article: H. Mirhosseini, T. M. A. Müller, M. Krack, T. D. Kühne,
and J. Hutter, "The UZH protocol: Separating errors and constructing improved
CP2K basis sets and pseudopotentials", *J. Chem. Phys.* **165**, 104103 (2026),
[doi:10.1063/5.0347392](https://doi.org/10.1063/5.0347392).

`POTENTIAL_UZH` is the unmodified native separable-GTH parameter file from
[the UZH release](https://github.com/DCM-Uni-Paderborn/UZH-protocol/tree/acb98bb0d465d0a731ffdeca48107b2e56c3ab91/cp2k-data).
SHA-256: `8ab49093391f67f2705679f0b3bfc5b84bbeb4003955b556ded322e9d1d6093d`.
Original provenance and licensing are preserved; see the source repository's
[license](https://github.com/DCM-Uni-Paderborn/UZH-protocol/blob/acb98bb0d465d0a731ffdeca48107b2e56c3ab91/LICENSE)
and the original [CP2K data](https://github.com/cp2k/cp2k/tree/master/data).

This is curator/source material, **not a registered BSE pseudopotential**.
Separable GTH projector radii and symmetric coupling matrices cannot be
replaced by the semilocal-ECP records in the present BSE schema. The BSE
orbital entries therefore do not include an ECP or a separable potential.

`basis-potential-pairing.csv` specifies the matching native potential for
each of the 882 imported element/basis records, preserving the functional
and the explicit-electron count `q`. The 108 all-electron basis records use
`ALL`; a GTH variant with `q` equal to the atomic number is not relabeled
as an all-electron Hamiltonian.

The native file contains 488 syntactically complete GTH records, 36 `ALL`
definitions, and 90 explicit `NA` placeholders. One additional entry,
`Bi GTH-PBE0-q15`, is incomplete: the final diagonal coupling of its last
projector channel is missing. None of the imported orbital bases is paired
with that entry or an `NA` placeholder. No missing parameter has been inferred
or substituted. The complete validation report is deposited in the UZH
repository under `contributions/basis-set-exchange/validation.json`.

The adjacent `*.1.cp2k.bz2` files are native orbital-basis records grouped
by one functional/core variant per element for the existing BSE authoritative
source tests. They preserve the numerical source strings, rather than being
generated by the BSE exporter.
